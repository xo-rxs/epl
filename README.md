# EPL (Easy Pick League) 🎯⚽

**아마추어 축구 경기 자동 매칭 및 팀 배정 플랫폼**

## 프로젝트 소개

EPL은 축구 모임의 인원 관리, 팀 배정, 경기 준비 과정을 자동화하는 웹 플랫폼입니다.

### 핵심 문제 해결
- ❌ **기존**: 총무가 수작업으로 1시간 이상 소요되는 인원 취합 및 팀 배정
- ✅ **EPL**: 자동 참여 폼, 알고리즘 기반 팀 배정, 시각적 전술 배치도로 전체 과정 자동화

---

## 주요 기능

### 1️⃣ 매치 모집 및 참여 취합
- 관리자가 경기 정보(일시, 장소, 정원) 입력
- 참가자가 닉네임, 학년, 포지션 선택해 즉시 참여 등록
- **기술**: LocalStorage 기반 실시간 데이터 관리 + CSV 내보내기

### 2️⃣ 지능형 팀 빌딩 알고리즘
- 참여자 실력과 학년을 기반으로 균형 잡힌 두 팀 자동 구성
- Snake Draft 알고리즘 + 학년 가중치 필터
- **기술**: 클라이언트 단 알고리즘 실행, '재배정' 버튼으로 즉시 재생성

### 3️⃣ 드래그 앤 드롭 전술 배치도
- 축구장 형태의 UI에서 팀원 아이콘을 드래그해 포지션 배치
- 완성된 전술도를 PNG로 저장 및 SNS 공유
- **기술**: dnd-kit (드래그) + html2canvas (이미지 저장)

### 4️⃣ 경기 후 별점 리뷰 시스템
- 경기 후 참가자 간 상호 평가 (실력, 매너)
- 누적 점수를 레이더 차트로 시각화한 개인 프로필
- **기술**: Chart.js 시각화 + LocalStorage 누적 저장

## 빠른 시작

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

`http://localhost:5173` 에서 애플리케이션이 실행됩니다.

### 빌드

```bash
npm run build
```

최적화된 프로덕션 빌드가 `dist/` 폴더에 생성됩니다.

### Lint 검사

```bash
npm run lint
```

## 서비스 시나리오

### 시나리오 1: 총무 김철수의 자동 팀 배정
- 📊 인스타그램 투표 → 자동 명단 수집 → 클릭 한 번에 팀 배정 완료
- 기대 효과: 1시간 → 5분 단축, 공정한 배분

### 시나리오 2: 신입생 이영희의 포지션 확인
- 🎯 경기 전 시각적 전술도로 내 포지션 확인
- 기대 효과: 경기 시작 전 불안감 제거

### 시나리오 3: 박지성의 신뢰도 기반 매칭
- ⭐ 상호 평가로 축적된 실력 지표로 공정한 팀 구성
- 기대 효과: 비매너 플레이 억제, 신뢰도 높은 커뮤니티
