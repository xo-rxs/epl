# 2026-05-27 개발 일지

## 1. 개발 일지 (10점)

### 학습한 내용 및 활동 결과
오늘은 경기 페이지 UX 개편과 평가 페이지를 중심으로 개발을 진행했다. 경기 목록/생성/참여/관리로 화면 흐름을 분리하고, URL 파라미터로 뷰를 동기화해 사용성이 높아졌다. 참여 버튼과 목록 복귀 버튼의 가시성을 개선했고, 경기 목록 카드 클릭 시 기본적으로 참여 화면으로 이동하도록 수정했다. 전술 배치도는 11대11 4-3-3 포메이션 기본 배치로 변경했다. 또한 평가 페이지를 새로 만들고, 매치 생성자가 한 명씩 넘기며 별점과 태그를 선택하는 방식으로 평가하도록 UX를 재설계했다. 태그는 긍정/부정 그룹으로 분리하고 이모티콘을 포함해 직관성을 높였다.

### 고찰 및 추후 개발 계획 (100자 이상)
평가 UX를 단순화해 입력 부담을 줄일 수 있었지만, 태그 목록과 별점만으로 충분한지에 대한 검증이 필요하다. 다음에는 평가 완료 후 요약 리포트(평균 점수, 빈도 높은 태그)를 제공하고, 경기 상태가 준비 완료일 때만 평가가 가능하도록 제한할 계획이다. 또한 관리자 전용 기능(관리 페이지 접근 권한)도 검토한다.

## 2. 이슈 발생 처리 (10점)

### 발생한 이슈
- 모두 승인 기능이 참여자를 순차적으로 업데이트하면서 UI에서 한 명씩 승인되는 것처럼 보여 사용자 혼란이 발생했다.

### 해결 방법 
문제 원인을 확인해 보니 `updateParticipant`를 반복 호출하면서 상태가 여러 번 갱신되었고, 그 과정이 UI에 단계적으로 반영되었다. 이를 해결하기 위해 승인 대상 참여자 목록을 먼저 필터링한 뒤, 승인 상태를 반영한 전체 참여자 배열을 한 번에 구성해 `updateMatch`로 일괄 저장했다. 이 방식으로 단일 상태 업데이트가 이뤄져 UI가 한 번에 갱신되며 사용자 경험이 개선되었다.
