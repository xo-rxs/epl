# EPL(Easy Pick League) - 요구사항 명세서

## 프로젝트 개요
EPL은 아마추어 축구 경기 참여자들을 위한 매칭 및 팀 배정 플랫폼입니다. 
불편한 수작업 인원 취합과 팀 배정 과정을 자동화하여, 공정하고 투명한 경기 운영을 지원합니다.

---

## 주요 서비스 기능

### ① 매치 모집 및 참여 취합 서비스

**기능 설명**
- 관리자(총무)가 경기 일시, 장소, 정원을 입력하면 참여 폼 생성
- 참가자는 닉네임·학년·포지션을 선택해 즉시 참여 의사 등록

**프론트엔드 구현**
- React State 및 LocalStorage를 활용해 참여자 명단을 브라우저 내에서 실시간으로 관리
- 별도 서버 없이 링크 공유만으로 참여 현황 확인 가능
- 명단 CSV 내보내기 기능 제공

**기술스택**
- React Hooks (useState, useEffect)
- LocalStorage API
- CSV 내보내기 라이브러리

---

### ② 지능형 팀 빌딩 알고리즘

**기능 설명**
- 참여자의 실력 점수와 학년 데이터를 기반으로 전력이 균형 잡힌 두 팀 자동 구성
- 학년 쏠림 방지를 위한 가중치 필터 적용

**프론트엔드 구현**
- 프론트엔드 단에서 Snake Draft 알고리즘 직접 실행
- '재배정' 버튼으로 즉시 새 조합 생성 가능
- 학년 쏠림 방지 필터를 클라이언트 내에서 처리

**알고리즘 로직**
1. 참여자를 실력 점수순으로 정렬
2. Snake Draft 방식으로 팀 배분
3. 학년 가중치 검증 후 결과 생성
4. 사용자 요청 시 재배정 수행

**기술스택**
- JavaScript 알고리즘 구현
- React 상태 관리

---

### ③ 드래그 앤 드롭 전술 포지션 배치도

**기능 설명**
- 축구장 형태의 UI 위에서 팀원 아이콘을 자유롭게 드래그하여 포지션 배치
- 디지털 전술판 기능 제공

**프론트엔드 구현**
- dnd-kit 라이브러리로 모바일 터치 및 웹 드래그 모두 지원
- 배치 완료 후 html2canvas로 PNG 이미지 저장 가능
- 카카오톡·인스타그램 등 SNS로 즉시 공유 기능

**기술스택**
- dnd-kit (드래그 앤 드롭)
- html2canvas (이미지 캡처)
- SVG 또는 Canvas (축구장 UI)

---

### ④ 경기 후 상호 별점 리뷰 시스템

**기능 설명**
- 경기 종료 후 참여자끼리 실력과 매너를 별점으로 평가
- 결과는 개인 프로필에 누적 표시

**프론트엔드 구현**
- 별점 컴포넌트로 직관적인 평가 UI 제공
- 누적 점수는 LocalStorage에 저장
- 레이더 차트(Chart.js 등)로 데이터 시각화
- 서버 없이도 같은 기기에서 지속적 데이터 확인 가능

**저장 정보**
- 개인별 실력 점수
- 개인별 매너 점수
- 평가 이력

**기술스택**
- Chart.js (레이더 차트 시각화)
- React Star Rating 컴포넌트
- LocalStorage

## 서비스 시나리오

### [시나리오 1] 자동 팀 배정으로 인원 관리 자동화

**상황**
- 축구 모임 총무 김철수 씨는 매주 인스타그램 투표 결과를 메모장에 옮겨 적으며 인원 확정 및 팀 배정에 매번 1시간 이상 소요

**니즈**
- 투표 결과가 실시간으로 명단화되고, 팀까지 자동으로 짜주는 시스템

**불편사항**
- 수작업 과정에서 인원 누락 실수가 잦음
- 팀을 나누는 과정이 너무 주관적이고 피곤함

**제공 기능**
- LocalStorage 기반 실시간 참여 취합
- 실력·학년 기반 자동 팀 빌딩 알고리즘
- CSV 내보내기

**기대 효과**
- 인원 관리 시간 80% 단축
- 객관적인 팀 배분으로 공정성 향상

---

### [시나리오 2] 시각적 전술 배치로 경기 준비 강화

**상황**
- 신입생 이영희 씨는 선배들과 처음 축구 경기에 참여하게 되었는데, 본인이 어떤 포지션에서 뛰어야 하는지 몰라 경기장에서 당황

**니즈**
- 경기 시작 전에 내가 어디서 뛰어야 하는지 그림으로 미리 보고 싶음

**불편사항**
- 텍스트로 된 명단만으로는 실제 운동장에서의 내 위치나 전술적 움직임을 이해하기 어려움

**제공 기능**
- 드래그 앤 드롭 포지션 배치 보드
- html2canvas 기반 이미지 저장
- SNS 공유 기능

**기대 효과**
- 신입 참가자의 진입 장벽 낮춤
- 경기 전 충분한 준비로 경기 만족도 향상

---

### [시나리오 3] 객관적 평가로 신뢰도 기반 매칭

**상황**
- 박지성 씨는 실력이 비슷한 팀원들과 경기하고 싶지만, 실력을 속이거나 비매너 플레이를 하는 사람 때문에 경기가 망가질 때가 있음

**니즈**
- 같이 뛰는 사람들의 실력과 매너 점수를 미리 알 수 있으면 좋음

**불편사항**
- 유저의 실력을 증명할 객관적인 지표가 없어 팀 밸런싱이 무너지는 경우가 많음

**제공 기능**
- 상호 별점 리뷰 시스템
- LocalStorage 기반 누적 데이터
- 레이더 차트 시각화 프로필 기능

**기대 효과**
- 신뢰도 기반 공정한 매칭 시스템 구현
- 비매너 플레이 억제 효과
